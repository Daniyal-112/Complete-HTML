View Page Source:

View Page Source shows the original HTML code of a webpage as it was loaded by the browser. It helps beginners understand the basic structure of a website, including tags like headings, paragraphs, links, and images. However, it does not show live changes made by CSS or JavaScript, so it’s mainly useful for learning and analyzing static HTML.

How to Open:
  1. Right-click anywhere on the webpage → Click View Page Source
  2. OR press Ctrl + U

Inspect Element:

Inspect Element opens the browser’s Developer Tools, allowing you to view and edit HTML and CSS in real time. You can click on different elements to see their structure, styles, spacing, and layout. It is very useful for debugging issues, testing design changes instantly, and understanding how modern websites are built.

How to Open:
  1. Right-click on any element → Click Inspect
  2. OR press Ctrl + Shift + I

Different Screen Sizes:

Responsive View allows you to simulate how a website looks on different devices like mobile phones, tablets, and desktops. You can select various screen sizes or set custom dimensions. This helps ensure that your website is responsive and provides a good user experience across all devices.

How to Open:
  1. Open Inspect Element
  2. Click on the Device Toolbar icon
  3. OR press Ctrl + Shift + M
