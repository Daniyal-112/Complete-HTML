Image Tag:

  1. use to embed images
  2. Utilizes the src attribute for image URL
  3. alt attribute for alternative text
  4. Can be resized using width and height
  5. Self closing tag

Syntax;

<img src = "/image Path" alt =Your Text" >

Video Tag

  1. Embeds video files on a page.
  2. Uses src attributes for video URL.
  3. Supports multiple formats like MP4,WebM.
  4. Allows for built in control via attributes like autoplay controls and loop

Attributes

  1. Controls
  2. height
  3. width
  4. loop
  5. autoplay
  6. alt
  7. muted

Syntax;

<video src ="Video Path" Attributes>
