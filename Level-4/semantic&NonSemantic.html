Semantic Tag:

Semantic tags are HTML tags that clearly describe the meaning and purpose of the content they contain. They make the webpage structure more understandable for developers, browsers, and search engines. Semantic tags explain what kind of content is inside them.

Common Semantic Tags:
  • <header> → Represents the top section of a webpage or section
  • <nav> → Used for navigation links or menus
  • <main> → Contains the main content of the webpage
  • <section> → Groups related content together
  • <article> → Represents independent content like blog posts or articles
  • <aside> → Contains side content such as ads or sidebars
  • <footer> → Represents the bottom section of a webpage
Why Semantic Tags are Important:
  • Improve code readability and structure
  • Help search engines understand webpage content (SEO)
  • Make websites more accessible for screen readers
  • Easier for developers to maintain and understand code

Non Semantic Tag:

Non-semantic tags are HTML tags that do not describe the meaning of their content. They are mainly used for styling, layout, or grouping elements without giving any information about the purpose of the content. These tags do not help browsers or search engines understand what the content represents.

Common Non Semantic Tags:
  • <div> → Used as a container to group elements
  • <span> → Used to style or group small inline content
Why Non-Semantic Tags are Used:
  • Helpful for designing layouts with CSS
  • Used for applying styles or JavaScript functionality
  • Flexible and commonly used in web development
